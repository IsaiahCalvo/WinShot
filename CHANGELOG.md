# Changelog

## 1.6.0 - 2026-10-12

- Removed the extra preview that opened when hovering over a tall screenshot's corner thumbnail.
- Fixed capture selectors after dock, display, and monitor changes.
- Simplified the selector controls and improved capture, magnifier, and overlay motion.
- Updated annotation tools, editor controls, icons, keyboard focus, and layouts at different display scales.
- Improved corner-card actions, edited-image handoff, drag-and-drop files, and stacked captures.
- Improved recording dialogs, history, settings, and browser capture reliability.
- Bundled third-party notices with the app.
- Set the local build version to match the release and verified the release with the Windows test suite.
- Fixed the local install script to stage a build before replacing the app and stop on publish errors.

This release includes the accumulated desktop and browser-capture work since 1.5.0. The full commit history remains on GitHub.
