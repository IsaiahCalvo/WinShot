# WinShot 1.6.0

The corner thumbnail no longer opens an extra preview when you hover over tall screenshots.

This release also brings the accumulated capture, annotation, recording, history, settings, and browser-capture improvements into the published app:

- Capture selectors recover after monitor and dock changes.
- Selector controls are simpler, with smoother capture and magnifier motion.
- Annotation tools, icons, keyboard focus, and display scaling have been updated.
- Corner actions handle edited captures, stacked cards, and file drag-and-drop more reliably.
- Recording dialogs, history, settings, and browser capture include fixes from the current development branch.
- Third-party notices ship with the app.

The app reports version 1.6.0. Local release checks run the Windows test suite on a hidden desktop; GitHub also runs the existing CI package checks.

Download **WinShot-Setup.exe** for the installer, or **WinShot-win-x64.zip** for the portable package. The installer updates the existing per-user WinShot folder.

See [CHANGELOG.md](https://github.com/IsaiahCalvo/WinShot/blob/main/CHANGELOG.md) and the [full commit history](https://github.com/IsaiahCalvo/WinShot/compare/v1.5.0...v1.6.0).
